# dawitanelay.dev

Hugo-based personal blog scaffold. Contains minimal configuration, a sample post, and GitHub Actions for publishing to GitHub Pages.

Next steps:
- Create a GitHub repo named `dawitanelay.dev` and push `main` branch.
- Enable Pages to use the `gh-pages` branch (Actions will create it).
- Add DNS `A` records and a `CNAME` pointing `dawitanelay.dev` to GitHub Pages, or follow GitHub Pages docs for custom domains.
